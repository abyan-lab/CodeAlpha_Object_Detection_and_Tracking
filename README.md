# CodeAlpha Object Detection and Tracking 👁️🎯

> A computer vision application utilizing Python, OpenCV, and pre-trained models to detect, identify, and track objects across video frames as part of the CodeAlpha Python internship.

## ✨ Core Features & Functionality
- **Computer Vision Processing:** Processes video streams and image frames using OpenCV and advanced object detection frameworks.
- **Object Identification & Bounding Boxes:** Detects target objects within frames, highlighting them with precise bounding boxes and class labels.
- **Sequential Tracking Logic:** Follows identified objects across consecutive video frames to monitor motion and spatial changes.
- **Real-Time Visual Output:** Renders processed output windows or saves tracked video results with console logs and metrics.
